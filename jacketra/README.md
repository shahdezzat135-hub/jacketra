# 2W-D03-M - Build a Bootstrap Catalog Page

**Program:** Web Team Trainee Program - 2 Weeks  
**Level:** Medium  
**Suggested time:** 150 minutes

## Scenario
Use a starter dataset and markup placeholders to create a responsive product catalog.

## Required work
- Add navbar, filters, cards, badges, pagination, and a quick-view modal
- Use Bootstrap utilities before writing custom CSS
- Make the filter panel usable on mobile

## Acceptance criteria
- [ ] Modal opens from each card
- [ ] Layout is responsive
- [ ] Form controls have labels
- [ ] Custom CSS stays below 40 lines

## Submission
1. Do not replace the whole starter unless the task explicitly says so.
2. Add a `CHANGELOG.md` or `BUG_REPORT.md` when requested.
3. Keep the starter folder structure.
4. Demonstrate the result and explain the main decisions.
